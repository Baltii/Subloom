# Dashboard charts

The overview adds a selectable six-month charge forecast and animated category cost bars with monthly/yearly views. Choose a currency to update the overview and both charts; currencies are never converted or added together. Month bars expose the exact recorded-price projection and up to three subscription links.

The first forecast month covers today onward; weekly/custom subscriptions may contribute multiple charges. Trial endings assume conversion at the recorded price. Canceled access deadlines do not count as charges. These projections are not payment history. Category costs normalize active subscriptions/trials using the existing rational arithmetic and round at category totals.

Uses the existing Reanimated stack, bounded date-only recurrence expansion, reduced-motion alternatives and accessible text labels. Includes project agent guidance and a Subloom UI engineering skill. No new runtime dependency, database migration, credential or deployment required.
