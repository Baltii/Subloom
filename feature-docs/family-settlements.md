# Family Settlement Center

PR 8 of 8, based on Value Coach. Merge Cards & Wallets → Radar → Cancellation Watch → Autopilot → Virtual Card Plans → Renewal Reserve → Value Coach → Family Settlements. Apply the included family_settlements migration, then deploy the changed export-data function with the existing backend workflow. No hosted changes are applied by this PR.

Members view a shared ledger. The billing owner or workspace owner records a paid shared charge at the current price/split; the snapshot becomes immutable. Only the recipient or workspace owner records received settlements or request drafts. Balances net actual recorded charges and settlements by participant pair and original currency; projections and requests do not create debt. A record's author or workspace owner can void/restore it with version checks. Deleting a shared subscription leaves its historical entry; deleting a workspace/account cascades applicable owned entries and never blocks existing deletion.

Requests remain drafts with on-screen due labels and text export; no message, payment request link or money transfer is sent. Records are user supplied, not bank/provider confirmations. All reads/writes use the account session and membership RLS. Insert validation checks current members and the exact shared snapshot. New database functions use SECURITY INVOKER; no new privileged public RPC is introduced. Complete history is read atomically as one JSON result, capped at 2000 entries with a clear error rather than calculating partial balances. Guest/demo users must sign in for shared records. Cloud account export includes the ledger under the user's membership-scoped client.
